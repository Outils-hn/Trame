## Architecture
- Trame computes drilling distributions only (by number of intervals, fixed pitch, maximum pitch). The former hidden modules (reinforced zone, obstacle, panels, expansion) and PDF/DXF exports were removed on purpose; results are shown on screen and copied.
- All calculations live in src/lib/trame-calc.ts (pure code, tested in trame-calc.test.ts); the UI in src/routes/index.tsx only displays them.
- Vocabulary: the distance between the edge and the first/last hole is always "distance au bord" (début / fin), never "rive", "marge" or "pince".
- With whole millimetres, an odd remainder is never split by rounding both sides: the start is rounded down and the end takes the rest, so start + intervals + end always equals the total length.
- Data (history) stays in localStorage only, no backend.
- Every mode shows the same view (src/components/trame/ResultsView.tsx): a compact clickable table of options (no positions column) and a detail panel for the selected one (bar schema, cumulative positions, copy). Modes are normalised to DrillOption in trame-calc.ts; a "mm ronds" badge flags options whose pitch and start distance are whole millimetres.
- Visual identity shared with Linear and Format: uppercase letter-spaced section titles, tabular (non-mono) numbers in fields, the same discreet footer signature and About dialog (src/lib/version.ts is the single source for name/version/author). Trame keeps its own accent: copper (--color-trame in styles.css, lighter in .dark).
- The maximum-pitch tab has a "Une pièce / Plusieurs pièces" switch (only there). Multi-piece reads a Repère/Longueur list (pasted from Excel or typed, parsePieces) and shows one row per piece with its retained option: the fewest holes under the maximum pitch (buildMultiPieceOptions). Pieces without a solution are listed under the table; the table can be copied for Excel (piecesTable).
- The detail panel shows the AutoCAD helper "COPIER → Réseau → N éléments → @pitch<0"; the value always uses a decimal point (cadPitch), never the French comma.
- Background: light grey page (same tone as Format) with a dot-grid pattern echoing the logo (minor dots every 12 px, stronger dot every 60 px); the page wrapper must stay transparent so the body pattern shows.
- The bar schema is drawn like a drawing dimension: a chain line (start distance, "N × pitch = span", end distance; narrow edge labels go outside the piece) and the overall length below.
- The detail panel also offers the AutoCAD dimension text override "N x pitch = <>" (chainText, decimal comma) when there are at least 2 intervals.
- In the maximum-pitch tab (single piece), the first row carries a "conseillé" badge: fewest holes under the maximum pitch.
- Values meant to be pasted (AutoCAD input, dimension text) use the codeCls style: monospace without ligatures, each helper kept on one line.
- Full backup (src/lib/full-backup.ts, pure and tested; config in src/lib/backup-config.ts): the footer "Sauvegarde" link downloads every localStorage key owned by the app into one .json and restores it; restore validates app/kind/version, first downloads the current data as "-avant-restauration", replaces only this app's keys, then reloads. BackupReminder shows a dismissible pill when data exists and the last backup is older than reminderDays (null = no reminder). The same two files are shared verbatim by Linear, Format and Trame.
- Small helper texts sit on the dotted background, so they use foreground with opacity (text-foreground/60 to /75) rather than muted-foreground, to stay readable.
- Small helper texts placed on the dotted background (result count hint, units note, footer signature) keep their muted colours but sit on a light bg-background pill so the dots never run behind the letters.
